
# 📋 Java-Kanban

**Java-Kanban** — это приложение для управления задачами в формате доски Kanban.  
Поддерживает работу с задачами, эпиками и подзадачами, отслеживание истории, приоритетов и предоставляет REST API для взаимодействия.

---

## 🚀 Возможности

- Создание задач, эпиков и подзадач
- Подсчёт статуса эпика на основе статусов подзадач
- История просмотров задач
- Приоритизация задач по времени начала
- Хранение задач в памяти и в файле
- Веб-сервер с REST API на базе `HttpServer`

## ⚙️ Архитектура

Проект реализует:

- **TaskManager** — интерфейс менеджера задач
- **InMemoryTaskManager** и **FileBackedTaskManager** — реализация в памяти и с файловым сохранением
- **HttpTaskServer** — REST API-сервер
- Обработчики: `TasksHandler`, `EpicsHandler`, `SubtasksHandler`, `HistoryHandler`, `PrioritizedHandler`

---

## 🔄 Основные компоненты

- 📌 `Task`, `Epic`, `Subtask` — модели задач
- 🧠 `HistoryManager` — менеджер истории просмотров
- 💾 `FileBackedTaskManager` — хранение задач в CSV-файле
- 🌐 `HttpTaskServer` — REST API на `localhost:8080`
- 📊 `Managers` — точка доступа к менеджерам

---

## 🗃️ Схема данных

Модели:

- `Task` — обычная задача
- `Epic` — задача с подзадачами
- `Subtask` — подзадача, привязанная к эпик-записи

Задачи могут иметь статус: `NEW`, `IN_PROGRESS`, `DONE`.  
Epic автоматически обновляет свой статус в зависимости от подзадач.

## 🐳 Запуск проекта

### Через IntelliJ IDEA

1. Открыть проект `java-kanban`
2. Запустить `Main.java` или `HttpTaskServer.java`
3. Взаимодействовать через API или консоль

---

## 📖 Пример API (локально)

- `GET /tasks/task` — получить все задачи
- `POST /tasks/task` — добавить задачу
- `GET /tasks/epic` — получить эпики
- `GET /tasks/subtask` — получить подзадачи
- `GET /tasks/history` — история просмотров
- `GET /tasks` — получить задачи по приоритету
